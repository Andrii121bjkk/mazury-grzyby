# Grzyby Mazury — готовий вебпроєкт

Мобільна PWA-карта для Пущі Піської. Орієнтовна зона: Nadleśnictwo Pisz, Maskulińskie та Spychowo.

## Що всередині
- Leaflet + OpenStreetMap.
- Реальні полігони лісових виділів з офіційного BDL OGC API.
- Пагінація BDL та BBOX-запити лише для поточного вікна карти.
- 6 грибів: польський гриб, боровик, курка, козляки, масляк, каня.
- Режими: зараз / сухо / нормально / мокро.
- Погодний шар логіки: поточна температура, вологість та температура ґрунту 0–7 см, опади за 7 днів, прогноз до 10 днів.
- Модельний бал 0–100 і перцентильне забарвлення полігонів.
- «Куди їхати?» та рейтинг топових виділів.
- Геолокація.
- Google Maps: авто та пішки.
- OSRM-проксі для оцінки автомобільної відстані/часу від GPS до вибраного виділу.
- Шари: BDL виділи, аерофото Geoportal, рельєф NMT, тимчасові заборони, пожежна небезпека, туристичні об’єкти/маршрути, пожежні дороги.
- PWA/service worker для швидкого повторного відкриття оболонки.
- Serverless API: BDL, Open-Meteo, OSRM.

## Важливо про модель
Це модельна підказка, а не ботанічна гарантія. Оригінальний Janów-файл, на який спирається архітектура, прямо зазначає, що його ваги є гіпотезами без калібрування на польових спостереженнях. Тут для Мазур використовується окремий евристичний профіль, щоб не переносити ваги Janów як нібито валідовані.

## Публікація за 1 команду
Потрібен Cloudflare Pages.

[bash]
npx wrangler login
npx wrangler pages project create mazury-grzyby
npx wrangler pages deploy public --project-name mazury-grzyby


Для Functions залишай каталог [functions/] у корені цього проєкту. У Cloudflare Pages Functions маршрути формуються за файловою структурою [/functions]; наприклад [functions/api/bdl.js] дає [/api/bdl].

## Легальність / доступ
На карті присутній окремий шар тимчасових заборон BDL, але жодна автоматична модель не замінює перевірку знаків на місці. «Пожежна дорога» або інша лісова дорога не означає дозвіл для приватного авто.
