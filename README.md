# Grzyby Warszawa — карта лісів у радіусі 100 км

[Відкрити сайт](https://mazury-grzyby.pages.dev/)

Мобільна карта для пошуку лісових ділянок навколо Варшави. Зелене пунктирне коло позначає радіус 100 км від центру міста.

## Можливості

- Лісові ділянки з офіційного Банку даних про ліси Польщі (BDL).
- Орієнтовна модельна оцінка для восьми видів грибів, зокрема опеньок і рижиків.
- Для опеньок і рижиків модель враховує сезон, породу дерев і погоду; у поясненні показані типові місця пошуку.
- Погода та вологість ґрунту для вибраної точки.
- Геолокація, вибір ділянки й побудова маршруту в Google Maps.
- Додаткові шари BDL: лісові дані, обмеження входу та пожежна небезпека.
- Встановлення як PWA на телефон.

Карта завантажує дані для видимої частини екрана й показує оцінені ділянки, центри яких потрапляють у коло 100 км.

## Про оцінки

Оцінка є орієнтиром за типом місця зростання, породою дерев, віком насадження, сезоном і погодою. Це не прогноз урожаю, не підтвердження наявності грибів і не визначення їстівності. Карта не має даних про пні та мертву деревину, тому для опеньок цей фактор треба перевіряти на місці. Перед поїздкою перевіряйте місцеві заборони й правила доступу до лісу. Не збирайте та не їжте гриби без упевненого визначення виду.

## Публікація

Cloudflare Pages автоматично оновлює сайт після змін у гілці `main` репозиторію. Сайт: https://mazury-grzyby.pages.dev/ . Статичні файли лежать у `public`, серверні маршрути — у `functions/api`.
